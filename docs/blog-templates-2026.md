## 怎么选

| 你的优先级 | 选 |
| --- | --- |
| 想最快上线、不想配构建 | Hugo + PaperMod |
| 想要现代交互、愿意写组件 | Astro + Cactus / Openblog |
| 需要 MDX、评论、搜索全家桶 | Next.js + tailwind-nextjs-starter-blog |
| 中文社区、二次元风格 | Fuwari / Firefly |
| 想做成作品集而不只是博客 | Magic Portfolio / AstroWind |
| GitHub Pages 零配置 | Jekyll + Chirpy |
