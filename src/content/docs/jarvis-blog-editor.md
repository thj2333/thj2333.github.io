## 一、启动

```bash
npm run editor        # http://127.0.0.1:4400
npm run dev           # 另开一个终端：保存后会热更新页面
```

- 只监听 `127.0.0.1`，外网访问不到。
- 端口被占用时换一个：`PORT=4500 npm run editor`。
- 想在预览里看到**真实排版**，先跑一次 `npm run build`——预览的样式是从 `dist/_astro` 里读的。

## 二、界面

| 区域 | 说明 |
| --- | --- |
| 顶栏 · 下拉框 | 切换文章，按期号倒序 |
| 顶栏 · 中间标签 | 当前文章的期号、分类、是否「持续更新」 |
| 顶栏 · 右侧 | 状态（已加载 / 未保存更改 / 已保存时间）+ 保存按钮 |
| 左栏 | 实时预览，顶部会自动拼出文章头（标题、期号、分类） |
| 右栏 | Markdown 源码，带行号，不自动折行 |
| 中间分隔条 | 可拖动调整左右比例 |

## 三、双击定位（核心功能）

在**左栏预览**里双击任意段落、标题、表格行：

1. 右栏光标跳到对应的源码行；
2. 整块内容被选中（段落 = 从段首到段尾）；
3. 状态栏提示「已定位到第 N 行」。

反过来也成立：光标在右栏移动时，左栏会用**红色虚线框**标出当前所在的块。

> 表格是整张表映射到表头那几行——双击任意单元格会定位到表格起始处，行内内容需要自己往下找。

## 四、快捷键

| 操作 | 快捷键 |
| --- | --- |
| 保存 | `⌘S` / `Ctrl+S` |
| 调整分栏 | 聚焦分隔条后按 `←` `→` |
| 定位 | 在左栏双击 |

## 五、保存

- 直接写回 `src/content/blog/*.md(x)`，**不是草稿箱**，保存即生效。
- 没保存就切文章会弹确认；直接关标签页也会拦一下。
- 同时开着 `npm run dev` 时，保存后页面会自动刷新。

## 六、常见问题

**预览是白底、没样式？**
`dist` 还没构建。跑一次 `npm run build`，刷新编辑器即可。

**双击没反应？**
只有带 `data-line` 的块能定位。纯文本行（比如代码块内部）不单独映射，双击会落到外层容器。

**改了 frontmatter 里的 `title` 但预览标题没变？**
预览头是在渲染时从 frontmatter 现读的，正常会跟着变；如果没变，检查 `title:` 后面有没有多余的引号或缩进。

**能新建文章吗？**
暂时不能。复制一个现有 `.md` 改 frontmatter 是最快的办法（`issue` 往上加一号）。

## 七、安全边界

- 写入路径限定在 `src/content/blog`，扩展名只允许 `.md` / `.mdx`。
- 请求体上限 4MB。
- 不校验 Markdown 语法，也不跑构建——存坏了要靠 `git diff` 救回来，所以**提交前先看一眼改动**。

## 八、文件位置

| 文件 | 作用 |
| --- | --- |
| `tools/editor/server.mjs` | 服务端：静态文件、Markdown 渲染、读写接口 |
| `tools/editor/public/index.html` | 界面骨架 |
| `tools/editor/public/editor.js` | 交互：加载、渲染、保存、双击定位、分栏拖拽 |
| `tools/editor/public/preview.html` | 预览 iframe 外壳，负责行号映射的接收与高亮 |
| `tools/editor/public/editor.css` | 编辑器自身样式（深色） |
