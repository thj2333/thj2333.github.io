## 这个功能是什么

Jarvis 负责**编程与网站建设**，站点编辑器是它的第一项能力：不用打开 IDE，直接在浏览器里浏览、编辑整个仓库的源码。

不只是博客——页面、组件、样式、数据、配置，凡是文本文件都能在这里改。

## 一、启动

```bash
cd ../jarvis && npm start        # http://127.0.0.1:4400
npm run dev           # 另开一个终端：保存后站点自动热更新
```

- 只监听 `127.0.0.1`，外网访问不到。
- 换端口：`PORT=4500 cd ../jarvis && npm start`。
- 预览样式取自 `dist/_astro`，想看到真实排版先跑一次 `npm run build`。

## 二、界面

```
┌──────────┬──────────────────┬──────────────────────┐
│ 文件树    │ 预览              │ 源码                  │
│ src/...  │ (仅 Markdown)     │ 行号 + 文本           │
└──────────┴──────────────────┴──────────────────────┘
```

| 区域 | 说明 |
| --- | --- |
| 顶栏 · 仓库按钮 | 切换 / 添加 / 扫描仓库 |
| 文件树 | 可折叠目录；`⌘P` 搜索 |
| 预览 | **站点**（内嵌 dev server）或 **渲染**（Markdown），左上角切换 |
| 源码 | 带行号、不折行；`⌘S` 保存 |
| 站点 ↗ | 用系统浏览器打开当前预览页面 |

## 二点五、实时预览

改 `.astro`、`.css`、组件时，左栏就是**跑起来的站**：

1. 自动探测 `127.0.0.1:4321`，没跑就显示「启动开发服务器」按钮（在仓库里执行 `npm run dev -- --port 4321`）
2. 按当前文件推断路由：`src/pages/archive/index.astro` → `/archive/`
3. **编辑 / 浏览两种模式**（预览栏右上角切换）：
   - **编辑**（默认）：点击、双击都只定位源码，**链接和按钮不会跳转**
   - **浏览**：完全放行，正常点链接、按按钮
4. **双击页面里的文字/按钮，右边跳到对应源码行**
5. 保存后自动刷新（等 600ms 让 HMR 先更新）
6. 切到 Markdown 文件时自动换成「渲染」模式，双击段落仍能定位源码行

定位是怎么做到的：dev 模式下 `src/integrations/jarvis-locate.mjs` 会给每个页面注入一小段脚本，双击时把元素的可见文字和当前路由发给 Jarvis；Jarvis 按「页面 → 组件 → 布局 → 其他」的顺序搜索这个文本，命中就打开文件并跳行。所以它靠文字匹配——纯图标会用父级文字，变量拼出来的文字可能对不上。

要在别的 Astro 仓库也得到这个能力，把 `jarvis/integrations/astro-jarvis-locate.mjs` 复制过去并在 `astro.config.mjs` 里注册即可。

## 三、能改哪些文件

| 范围 | 内容 |
| --- | --- |
| `src/` | 页面、组件、布局、样式、数据、内容 |
| `tools/` | 编辑器自身等本地工具 |
| `docs/` | 站点相关的调研文档 |
| `public/` | favicon、静态资源 |
| 根目录 | `astro.config.mjs`、`tsconfig.json`、`package.json`、`README.md` |

**不能改**：`node_modules`、`dist`、`.astro`、`.git`、`_backup`，以及任何非文本文件。路径会在服务端做一次 `path.resolve` + 白名单校验，越界的请求直接 400。

## 四、双击定位（仅 Markdown）

在预览里双击任意段落、标题、表格行：

1. 右边跳到对应源码行；
2. 整块被选中；
3. 状态栏提示「已定位到第 N 行」。

反过来：光标在代码区移动时，预览会用红色虚线框标出当前块。

> 表格整张映射到表头那几行，双击任意单元格都定位到表格起始处。

## 五、快速打开

- `⌘P` / `Ctrl+P` 打开文件面板；
- 输入路径片段过滤（比如 `archive/index`）；
- `↑` `↓` 选择，`↵` 打开，`esc` 关闭。

适合在几十个文件里跳，不用展开目录。

## 六、保存

- 直接写回磁盘，**没有草稿箱**，保存即生效。
- 未保存切换文件会弹确认；关标签页也会拦。
- 开着 `npm run dev` 时，保存后页面自动刷新。
- 服务端日志会打印每次保存：`[jarvis] saved src/pages/index.astro (12345 B)`。

## 七、常见问题

**预览是白底、没样式？** `dist` 还没构建。跑一次 `npm run build`。

**改了 `.astro` 左边没变化？** 正常——非 Markdown 没有实时预览。保存后点右上角「站点 ↗」看效果。

**双击没反应？** 只有带 `data-line` 的 Markdown 块能定位；代码块内部、纯文本行不单独映射。

**能新建文件吗？** 暂时不能，复制一个现有文件改是最快的办法。

## 八、文件位置

| 文件 | 作用 |
| --- | --- |
| `jarvis/server.mjs` | 文件树、读写接口、Markdown 渲染、路径校验 |
| `jarvis/public/index.html` | 界面骨架（文件树 / 预览 / 源码 / 面板） |
| `jarvis/public/app.js` | 交互逻辑 |
| `jarvis/public/preview.html` | 预览 iframe，接收行号映射与高亮 |
| `jarvis/public/app.css` | 控制台样式 |
